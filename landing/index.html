How to use Taski

1

Public page

Open stan-kondrat.github.io/taski/app/. Nothing to install. The only way to use Google Drive without your own setup.

2

Download and open

Download the single taski.html or the source folder, then just open the HTML file in your browser. Works offline.

3

Python static server

In the unzipped folder run python3 -m http.server 8000 and open localhost:8000/taski.html. Shows the taski-demo/ folder next to it, read-only.

4

Private server

Run python3 server.py --root ~/tasks on your computer or your own server. Files are stored there and edited from any browser.

Where your files can live, for each way

Way to run Folder on your computer Google Drive Files on the server Web folder
read-only		 Offline Setup
1 · Public page ✓ a ✓ – ✓ b – none
2 · Downloaded HTML, opened from disk ✓ a – c – ✓ b ✓ download
3 · python3 -m http.server ✓ a ✓ d read-only ✓ b ✓ one command
4 · python3 server.py ✓ a ✓ d ✓ read & write ✓ b ✓ e one command
  1. Read and write in Chrome, Edge, Arc, Brave and other Chromium browsers, on https://, localhost or a file opened from disk. Safari and Firefox open a folder read-only; to edit there, use way 4.
  2. An http(s):// address whose server allows cross-origin reads (GitHub Pages does). A page opened from disk can't read other files on disk by address, so for local files use a local folder or way 4.
  3. Google signs in only on a web address, so a downloaded file links to the public page for Drive.
  4. Needs your own Google OAuth client ID with this address as an allowed origin. See the setup guide.
  5. On your own computer. On a remote server, offline means "no internet needed besides your server".

Link to a workspace: add ?storage= (http, server, folder or drive) and &path=, for example taski.html?storage=server&path=work. All parameters.

Private server safety: server.py has no login. It listens only on 127.0.0.1, so reach a remote one through an SSH tunnel (ssh -L 8000:127.0.0.1:8000 your-server) or put it behind a reverse proxy with HTTPS and a password.

Files are the source of truth

Each project is a folder. Each task is a folder with a README.md or a single .md file. A short frontmatter block holds status, priority, due date and tags; everything else is free Markdown.

Taski only changes the lines it needs to, so your notes, extra fields and an agent's edits stay intact.

Private by design

Taski is a single static HTML page with plain JavaScript. It runs entirely in your browser and has no backend of its own — there is no Taski server that could see, store or lose your tasks.

Your files go straight from your browser to where you keep them: your disk, or your own Google Drive. Host the page anywhere static files are served, or open it from your own computer.

  • No account, no sign-up
  • No analytics, tracking or cookies
  • No third-party scripts — Google sign-in loads only if you choose Drive
  • Drive access token stays in the page's memory, never stored
  • Offline with a local folder or server.py on 127.0.0.1
  • Source on GitHub — read every line before you trust it

Small on purpose

Readable, no dependencies

Plain, commented JavaScript — never minified, even in the single-file download. Nothing to install.

Static and serverless

Host it on GitHub Pages, any static web server, or just open it locally. Nothing to run in the cloud.
