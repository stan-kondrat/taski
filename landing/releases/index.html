How to use it

Single file

  1. Download taski.html and put it anywhere — your desktop, a USB stick, a synced folder.
  2. Open it in your browser (double-click, or drag it into the window). The start screen shows what works in that browser.
  3. Click Choose folder… and pick an empty folder or an existing Taski workspace. In Chrome, Edge or Arc you can edit; allow it when the browser asks. Safari and Firefox open the folder read-only.
  4. Create a project and add tasks. They're saved as .md files in that folder, which you can also edit in any text editor.

Next time, open the file again and click Reopen. Taski remembers the folder in this browser only.

Source folder

  1. Download taski.zip and unzip it.
  2. Open taski.html the same way as the single file — it works straight from disk.
  3. Or, for any browser including Safari and Firefox, run python3 server.py in that folder and open http://127.0.0.1:8000/taski.html. It starts with the sample workspace; use --root to point at your own.

Every file is plain, commented JavaScript and CSS. Read it, change it, keep it — under the JSON License.

What works where

Taski runs four ways — public page, downloaded file, Python static server, or your own server.py — and each supports different storage. See the full matrix.
