# Milestones

Each project lists its milestones in its README frontmatter, in order and with an
optional date: `milestones: MVP (2026-11-30), 1.0`. A task joins one with
`milestone: MVP`.

- [x] `milestones` in the project README, `milestone` in tasks
- [x] Milestone field on the task page, chips in the list and board
- [x] Milestone progress on the project page, filtering by milestone
- [x] Next milestone on the overview cards
- [x] Milestones as a second level under each project in the sidebar
- [x] Archive and unarchive projects
- [ ] Rename a milestone across its tasks from Settings
