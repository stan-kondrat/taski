# Tiny GPT from scratch

Learn how language models really work by building one: tokenizer, attention,
training loop. Plain PyTorch, a ~10M-parameter model, trained on the RTX 3060 in
the desktop. Weekend evenings only.

Reading list: [references.md](./references.md).
